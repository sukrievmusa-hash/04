# 04 — Никах: прототип сервиса серьёзных знакомств

Черновик. Прототип сайта для знакомств с целью никаха (Казахстан и Россия): лента анкет с умным поиском и фильтрами по городу, возрасту, семейному положению, детям и переезду.

## Что умеет
- **Умный поиск** по фразе: «Девушки из Алматы до 25 лет», «врач из Астаны», «Алматы, без детей, покрытая». Система показывает, что поняла (город, пол, возраст, дети и т.д.), остальные слова ищет по тексту анкеты.
- **Фильтры:** кого ищу (жену / мужа), страна → город, возраст (двойной ползунок), семейное положение, дети, переезд. Счётчик анкет в реальном времени и «Сбросить фильтры».
- **Карточки анкет** в спокойных тонах: имя или «Имя при знакомстве», возраст, город, национальность, рост/вес, семейное положение, дети, о себе, требования.
- **Регистрация / вход** по телефону или Email — открывается при «Показать контакты».
- **Режим администратора** (ссылка «Вход для администратора» внизу страницы, пароль в `src/config.js`): только админ добавляет, меняет и удаляет анкеты.
- **Приватность:** «Скрывать номер, пока не одобрена заявка» — вместо контакта пользователи отправляют заявку.

Это прототип: сервера нет, анкеты и вход хранятся в браузере (localStorage), поэтому изменения админа видны только в его браузере. Пароль админа проверяется в браузере и виден в коде — для реального запуска нужен сервер (например, Supabase). 10 анкет — тестовые, контакты ненастоящие.

## Стек
React 18 + Tailwind CSS 3 + Vite. Сборка — один файл: `index.html` в корне (его и отдаёт GitHub Pages) и копия в `docs/`. Исходная страница — `web/index.html`.
Сайт: https://sukrievmusa-hash.github.io/04/

```bash
npm install
npm run dev     # локально
npm run build   # собрать в docs/
```

## Структура
- `src/data.js` — города, тестовые анкеты, примеры запросов
- `src/smartSearch.js` — разбор поисковой фразы
- `src/App.jsx` — интерфейс (шапка, поиск, фильтры, карточки, вход, форма анкеты)
